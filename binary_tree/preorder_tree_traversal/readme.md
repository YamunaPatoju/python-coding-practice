# Preorder Tree Traversal – Iterative and Recursive

## Problem Statement

Given the root of a binary tree, traverse the tree using preorder traversal.

In preorder traversal, nodes are visited in the following order:

**Root → Left → Right**

This problem is solved using both recursive and iterative approaches.

## Example

### Input

```text
        1
       / \
      2   3
     /   / \
    4   5   6
       / \
      7   8
