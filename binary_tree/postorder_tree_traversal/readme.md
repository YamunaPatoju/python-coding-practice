# Postorder Tree Traversal – Iterative and Recursive

## Problem Statement

Given the root of a binary tree, traverse the tree using postorder traversal.

In postorder traversal, nodes are visited in the following order:

**Left → Right → Root**

This problem is solved using both recursive and iterative approaches.

## Example

### Input

```text
        1
       / \
      2   3
     /   / \
    4   5   6
       / \
      7   8
