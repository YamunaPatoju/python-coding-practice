# Inorder Tree Traversal

## Problem Statement

Given a binary tree, traverse the tree using inorder traversal.

In inorder traversal, nodes are visited in the following order:

1. Left subtree
2. Root node
3. Right subtree

Both recursive and iterative approaches can be used.

## Example

### Input

```text
        1
       / \
      2   3
     /   / \
    4   5   6
       / \
      7   8
