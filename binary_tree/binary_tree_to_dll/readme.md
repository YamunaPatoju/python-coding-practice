# Binary Tree to DLL

## Problem

Given the root of a binary tree, convert it into a Doubly Linked List (DLL) in place.

The DLL should be formed according to the inorder traversal of the binary tree.

- Left pointer represents `prev`.
- Right pointer represents `next`.
- The leftmost node becomes the head of the DLL.

## Example

Input:

```text
    1
   / \
  3   2
