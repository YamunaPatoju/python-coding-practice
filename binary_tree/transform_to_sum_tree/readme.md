# Transform to Sum Tree

## Problem

Given the root of a binary tree, convert it into a Sum Tree.

The new value of each node should be equal to the sum of all values
in its left and right subtrees based on the original tree.

Leaf nodes are changed to `0`.

## Example

Input:

```text
        10
       /  \
     -2    6
     / \   / \
    8  -4 7  5
